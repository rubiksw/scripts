# Scripts

A collection of useful scripts for use in the windows context menu

## Contents

### Context Menu Scripts

#### Compress Materials
Located in `contextmenu/compressmaterials/`

Adds a "Compress VTFs" option to the folder context menu to compress .vtf files using the lean mean compression machine

#### Model Path Copy
Located in `contextmenu/modelpath/`

Adds a "Copy model path" option to .mdl files to copy the normalized path to clipboard.
