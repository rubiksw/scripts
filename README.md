# Scripts

A collection of useful Windows scripts for enhancing context menus and automating tasks.

## Contents

### Context Menu Scripts

#### Compress Materials
Located in `contextmenu/compressmaterials/`

Adds a "Compress VTFs" option to the folder context menu to compress .vtf files using lmcm.exe.

- See `readme.txt` for setup instructions.

#### Model Path Copy
Located in `contextmenu/modelpath/`

Adds a "Copy model path" option to .mdl files to copy the normalized path to clipboard.

- See `readme.txt` for setup instructions.
